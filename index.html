One-time setup: connect to Microsoft 365

This page reads and writes the tracker through the Microsoft Graph API using your own sign-in. It needs an Entra ID app registration (about five minutes, tenant admin).

  1. Entra admin center → App registrations → New registration. Name: Batch 3 Battery Recheck. Supported account types: this organization only.
  2. Under Redirect URI choose platform Single-page application (SPA) and paste this page's address:
  3. API permissions → Add → Microsoft Graph → Delegated → Files.ReadWrite.All (and User.Read). Grant admin consent so team members are not prompted.
  4. Copy the Application (client) ID and Directory (tenant) ID from the Overview page into Settings (⚙) here.

Anyone who opens this page must also have edit rights on the SharePoint file itself; Graph writes are made as the signed-in user and appear in the file's version history under their name.
